# Радар заказов — восемь источников

## Обновление GitHub
1. Распакуйте montage-radar-main.zip.
2. В корне репозитория: Code → Add file → Upload files.
3. Перетащите внутреннюю папку montage-radar целиком → Commit changes.
4. Дождитесь успешного запуска Actions.

Файл .github/workflows/main.yml и настройки cron-job.org менять не нужно. Внешнюю папку montage-radar-main не загружайте.

## Что изменилось
Добавлены WORK ON (workk_on) и ФРИЛАНС | ВАКАНСИИ | УДАЛЕНКА (freelancce). Остальные шесть источников сохранены.
Краткая подборка и полное объявление объединяются при общем контакте, совпадении формата, числовых условий и достаточном совпадении содержания. Все оригиналы сохраняются. Разные заказы одного контакта не объединяются только на основании контакта. Сильно изменённые перепосты могут не распознаться.

## Сохранено
- Показ за последние 72 часа, категории — единственный фильтр.
- Сбор по ранее настроенному расписанию 15 минут; cron-job.org запускает workflow_dispatch.
- Очистка сохранённых данных при первом сборе после двухчасового интервала; закрытые вакансии исключаются при каждом сборе.
- Кнопка перечитывает готовый список. Запрос запуска и успешная публикация — разные этапы.
- История отпечатков 30 дней, статистика источников семь дней. Статистика показывает находки, а не полученные заказы и не гарантирует надёжность клиента.
- Подборки rueventjob разделяются на отдельные вакансии; дата подборки не гарантирует дату исходного заказа.
