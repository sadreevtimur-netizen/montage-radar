# Радар заказов: обновление каждые 15 минут

## Загрузка в GitHub
1. Распакуйте montage-radar-main.zip. Внутри папки .github и montage-radar.
2. В корне репозитория: Code → Add file → Upload files. Перетащите папку montage-radar целиком → Commit changes.
3. Откройте в GitHub .github/workflows/main.yml → карандаш (Edit).
4. Замените весь текст содержимым .github/workflows/main.yml из архива → Commit changes.
5. Дождитесь зелёной галочки во вкладке Actions. Pages остаётся GitHub Actions.

Внешнюю папку montage-radar-main не загружайте. ZIP GitHub не распаковывает. Старые неиспользуемые дубликаты в репозитории это обновление не удаляет.

## Поведение
- Сбор и публикация назначены каждые 15 минут: на 7, 22, 37 и 52 минуте часа. GitHub может задерживать запуск.
- Очистка сохранённых вакансий выполняется при первом сборе после двух часов с прошлой очистки. При обновлении формата данных очистка выполняется сразу.
- Срок показа — 72 часа с публикации. Более старые карточки скрываются в браузере сразу, физически удаляются из списка при очистке. Закрытые поиски исключаются при каждом сборе.
- Кнопка Обновить список перечитывает готовые данные. Сама страница также перечитывает их каждые пять минут.
- Шесть источников. У rueventjob нумерованные подборки делятся на карточки монтажа с отдельными контактами. На них указана дата подборки: она не доказывает свежесть исходного заказа.
- Добавлено распознавание англоязычных заказов Video editor с условиями найма. Резюме и рекламные предложения по-прежнему отсекаются.
- Категории — единственный фильтр. Оригиналы доступны в каждой карточке.
- Отпечатки перепостов хранятся 30 дней, статистика источников — семь дней. Статистика не является подтверждением оплаты или надёжности заказчиков.
