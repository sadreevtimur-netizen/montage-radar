# Радар заказов — категории и вакансии за сутки

## Как обновить GitHub
1. Распакуйте montage-radar-main.zip.
2. Внутри находится папка montage-radar.
3. Откройте главную страницу репозитория montage-radar, вкладку Code.
4. Нажмите Add file → Upload files и перетащите папку montage-radar целиком.
5. Нажмите Commit changes и дождитесь завершения запуска во вкладке Actions.

В архиве пути уже соответствуют репозиторию. Не загружайте сам ZIP: GitHub его не распакует. Файл .github/workflows/main.yml менять не требуется: используется существующее почасовое расписание и публикация montage-radar/site.

## Как работает
- Единственный фильтр — категория видео.
- В ленте остаются только незакрытые публикации младше 24 часов.
- Возраст отсчитывается от публикации, а не от первого обнаружения.
- Сборщик удаляет старые объявления из списка при очередном запуске.
- Даже без нового сбора открытая страница проверяет возраст каждые 30 секунд и убирает просроченные карточки.
- Сбор новых публикаций запускается каждый час существующим GitHub Actions. Запуск может задерживаться; дата успешного сбора видна на сайте.
- Открытая страница перечитывает список каждые пять минут. Кнопка «Обновить список» перечитывает уже собранные данные.
- От старых объявлений на 30 дней сохраняются только отпечатки и даты для распознавания идентичных перепостов. Старые тексты в списке не хранятся. Изменённый перепост может не распознаться.
- Источники, оригиналы объявлений, контакты и текстовые признаки риска сохранены. Проверка источника не гарантирует надёжность заказчика.

## Проверка
python -m unittest discover -s tests -v

Интерфейс проверен в Edge: категории, исчезновение через 24 часа, исключение закрытых вакансий и мобильная ширина.
