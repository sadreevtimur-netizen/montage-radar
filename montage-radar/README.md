# hiki / радар заказов

Личный список публичных вакансий видеомонтажёра. Без платных API, библиотек и ключей Telegram. Сайт ничего никому не рассылает.

## Размещение на GitHub — один раз

1. Создайте **отдельный публичный репозиторий** `montage-radar` с основной веткой `main`. Портфолио `hiki34` менять не нужно.
2. Загрузите **содержимое этой папки**, включая скрытую папку `.github`, в корень репозитория. Если веб-загрузка её пропускает, создайте файл `.github/workflows/update.yml` через Add file → Create new file и вставьте содержимое приложенного файла. Код сборщика, `sources.json`, папки `tests` и `site` тоже должны быть в корне.
3. Откройте Settings → Pages → Source → **GitHub Actions**.
4. Во вкладке Actions выберите «Обновить вакансии и сайт» → Run workflow. При необходимости разрешите запуск Actions. После успешного запуска ссылка появится в Settings → Pages.

Адрес: `https://g05583306-cyber.github.io/montage-radar/`, **если** репозиторий создан под этим аккаунтом и с таким названием. Пока вы его не разместили, этот адрес не является опубликованным результатом.

Обновление назначено на 17-ю минуту каждого часа (UTC). GitHub может задерживать/пропускать запуски и отключать неактивные расписания. На сайте есть время последнего успешного сбора. Стандартные GitHub Actions для публичных репозиториев и Pages доступны бесплатно в пределах правил и лимитов GitHub. Это личный открытый проект, не коммерческая биржа с оплатой. Свой домен необязателен.

## Локальный запуск

Нужен Python 3.11 или новее. В этой папке выполните:

```sh
python collector.py
python -m http.server 8765 --directory site
```

Откройте `http://localhost:8765`. Двойной щелчок по HTML не заменяет веб-сервер: браузер может блокировать загрузку списка. Кнопка на сайте перечитывает готовые данные; она не запускает сборщик. Открытая страница сама перечитывает данные каждые пять минут.

## Источники и ограничения

В `sources.json` — пять известных профильных источников. Для нового источника добавьте его публичный username, название и `"enabled": true`. Не добавляйте закрытые чаты, личные переписки или источники, запрещающие такой сбор.

Сборщик читает до трёх страниц открытого веб-просмотра каждого канала. Это **не полный архив и не поиск по всему Telegram**. Для высокочастотных каналов охват 30 дней может быть неполным. Telegram иногда не отдаёт веб-ленту; тогда источник помечается недоступным, старые вакансии остаются. При полном сбое сайт получает статус ошибки, а запуск Actions завершается неуспешно.

Вакансии старше 30 дней удаляются из списка. Удаление/закрытие объявления самим автором автоматически не подтверждается: перед откликом проверяйте оригинал. Тексты, цены и контакты могут содержать ошибки авторов. Результаты отбора эвристические: возможны пропуски и лишние объявления. Дубликаты объединяются по нормализованному тексту или высокой схожести при общем контакте.

`site/data/jobs.json` содержит настоящие публичные объявления, а не примеры. Список и исходный код будут публичны. Не помещайте туда пароли, токены, личные переписки или приватные заметки. Изменения «сохранить / написал / скрыть» остаются в localStorage браузера и не синхронизируются между устройствами.

## Проверка рисков

Правила отмечают запросы взноса, кода входа, установки программы и наличие тестового. **Это не проверка личности, не чёрный список и не гарантия безопасности.** Наличие тестового не означает мошенничество. Эвристики учитывают некоторые отрицания, но не понимают весь контекст. Не найденный риск не означает, что риска нет. Внешние тексты не исполняются, ссылки на файлы не скачиваются.

## Проверки

```sh
python -m unittest discover -s tests -v
```

Проверяются отделение резюме от вакансий, обработка HTML, отрицания в предупреждениях и объединение дублей.

## Состав

- `site/` — только публикуемые файлы сайта.
- `collector.py` — сбор, фильтрация, риски, объединение дублей.
- `sources.json` — список источников.
- `.github/workflows/update.yml` — расписание, проверки, сохранение данных и публикация.
- `tests/` — проверки правил.

Система не использует Codex во время обновлений, платную модель или постоянно включённый домашний компьютер.
