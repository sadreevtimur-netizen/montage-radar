# Радар заказов: обновление 10 сентября 2026

Бесплатный сборщик открытых Telegram-лент для GitHub Pages. Не пишет заказчикам, не требует Telegram-аккаунта или платного API.

## Как обновить существующий репозиторий
1. Распакуйте монтажный архив `montage-radar-update.zip` на компьютере.
2. В репозитории `montage-radar` откройте папку `montage-radar` (внутреннюю).
3. Add file → Upload files: загрузите в неё содержимое папки `montage-radar` из архива, включая папки site и tests. Подтвердите Commit changes.
4. Существующий workflow совместим. Исправленный вариант также вложен в `.github/workflows/main.yml`: можно открыть этот файл в GitHub и заменить содержимое.
5. Откройте Actions. Запуск от изменения файлов собирает данные и публикует сайт; при необходимости Run workflow. GitHub Pages → Source: GitHub Actions остаётся как было.

Не загружайте ZIP как единственный файл: GitHub его не распакует. Корневые старые index.html/script.js не используются workflow: публикуется `montage-radar/site`.

## Изменения
- Пять включённых источников, просмотренных 10.09.2026. Причины включения/отключения в sources.json.
- Новые уникальные объявления за запуск отдельно от количества повторно прочитанных постов.
- По умолчанию 7 дней, скрыты обязательная съёмка и явно офисный формат; настройки можно переключить.
- Просмотренные, сохранённые, написанные и скрытые вакансии; отметки остаются в браузере.
- Поле firstSeenAt и сохранение идентификатора при распознанном перепосте.
- Отсев резюме, рекламы, смежных ролей с простым упоминанием монтажа; закрытые поиски не видны в основной ленте.
- Обновлённый текст поста заменяет кэш. Недавние посты перечитываются для обнаружения закрытий.
- До 8 страниц при начальном сборе. При обычном запуске — новые записи и минимум две страницы перекрытия. Полное покрытие не гарантируется; достижение лимита показано в статусе.
- Доступность канала и свежесть его вакансий показываются раздельно. Канал, в котором мало заказов, не создаёт новые объявления каждый час.

## Что означает «проверен источник»
Открыты публичные публикации, проверены даты, наличие задач по монтажу и способов отклика. Заказчики, факт оплаты и конверсия в заказы не проверены. Риск-фильтр — текстовые признаки, не антифрод-сервис с гарантией.

Первое расширение базы добавляет и старые объявления. «С прошлого визита» — время обнаружения сборщиком; дата публикации отдельно указана на карточке. Перепосты распознаются эвристикой, возможны пропуски. Закрытия старше просмотренного перекрытия могут обнаружиться не сразу.

## Проверка
Python 3.12, стандартная библиотека. `python -m unittest discover -s tests -v`, `python collector.py`.
Локальный просмотр: `python -m http.server 8080 --directory site` и http://localhost:8080.
Проверены шесть доступных кандидатов; один с нулём подходящих вакансий за неделю оставлен выключенным резервом. Повторный сбор без новых постов дал 0 новых. Интерфейс проверен в Chromium/Edge: загрузка, отметка «Просмотрел», фильтр источников, мобильная ширина, отсутствие ошибок JavaScript.
